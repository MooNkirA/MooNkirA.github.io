## 项目列表

### 品优购（电商系统）

基于 Dubbo + Spring + SpringMVC + MyBatis 的分布式电商系统，涵盖后台管理、前台门户、搜索、购物车、支付、秒杀等完整业务模块。

### 万信金融（P2P 金融）

基于 Spring Cloud Alibaba 的互联网金融系统，涵盖用户注册登录、开户、发标、投标、放款、还款、提现等完整金融业务流程。

### 学成在线（在线教育）

基于 Spring Cloud + Eureka + Zuul + RabbitMQ 的在线教育平台，涵盖 CMS 内容管理、课程管理、搜索、用户认证授权等模块。

### 好客租房（租房平台）

基于 React + Ant Design + Spring Boot + MyBatis-Plus 的租房服务平台，涵盖后台管理、阿里云 OSS、GraphQL 等技术。

### 品达通用权限系统

通用权限管理系统，涵盖权限数据模型、权限服务开发、网关服务开发等企业级权限解决方案。

### 红包雨场景案例

高并发红包雨场景的系统设计与项目开发实战。

### 国际物流云商系统

国际物流行业的云商平台系统。
